# 📅 Booking System

Полнофункциональное веб-приложение для бронирования услуг. Проект демонстрирует навыки работы с REST API, аутентификацией, разделением ролей и современным UI.

## 🚀 Функционал

### Для клиентов:
- 🔐 Регистрация и авторизация (JWT/Sanctum).
- 📋 Просмотр каталога услуг с ценами и длительностью.
-  Бронирование удобного времени.
- 👤 Личный кабинет с историей бронирований.

### Для администраторов:
- 👑 Отдельная админ-панель.
- ✅ Подтверждение или отмена заявок клиентов.
-  Управление каталогом услуг (создание, редактирование, удаление).
-  Просмотр всех бронирований в системе.

## 🛠 Технологический стек

**Frontend:**
- React.js (Vite)
- Tailwind CSS
- Framer Motion (анимации)
- Axios
- React Hot Toast

**Backend:**
- Laravel 10/11
- MySQL
- Laravel Sanctum (API Auth)
